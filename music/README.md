# Фонова музика

Сложете тук песни (`.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`, `.aiff`) и в `.env` задайте `MUSIC_PATH=music`.

- Пайплайнът разбърква песните (еднакво за един и същи проект), залепва ги с 3 s crossfade, докато покрият цялото видео, и ги заглушава автоматично под гласа.
- **Кредити:** ако лицензът изисква посочване на автора (напр. CC BY), сложете до песента текстов файл със същото име (`Песен.mp3` → `Песен.txt`) с текста на кредита. Той се добавя автоматично в описанието на видеото и (съкратено) на Shorts.
- Самите песни не се качват в git.

Безопасни източници за монетизирани видеа:

- **YouTube Audio Library** (YouTube Studio → Audio Library) – безплатна; при някои песни се изисква кредит (виж колоната „License type“).
- **Kevin MacLeod / incompetech.com** – CC BY 4.0, нужен е кредит във формата:

```
"Име на песента" Kevin MacLeod (incompetech.com)
Licensed under Creative Commons: By Attribution 4.0 License
http://creativecommons.org/licenses/by/4.0/
```

За TikTok: личните акаунти могат да ползват такава музика; бизнес акаунтите трябва да ползват Commercial Music Library на TikTok.
